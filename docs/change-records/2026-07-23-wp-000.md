## Hypothesis

A versioned change record, reusable runbooks, and incremental CI checks will make unsafe production changes visible before merge without changing application behavior or blocking unchanged legacy migrations. The hypothesis fails if the checks accept a newly changed destructive migration, reject documentation-only safe changes, or require production access.

## Canary

- Population: this WP-000 PR and its independent read-only audit.
